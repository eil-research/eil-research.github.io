# Efficient Inference and Learning Lab — website

Static site for the Efficient Inference and Learning Lab (Sejun Park,
Department of Artificial Intelligence, Korea University).

Built with the **jemdoc** template: `jemdoc.css` is the stock stylesheet, taken
verbatim from the POSTECH SDS Lab site (https://sds.postech.ac.kr/jemdoc.css),
and the pages use the standard jemdoc HTML structure — a two-cell layout table
(`#layout-menu` on the left, `#layout-content` on the right). The same template
is used by https://sds.postech.ac.kr, https://alinlab.kaist.ac.kr and
https://www.cs.toronto.edu/~erdogdu.

Note: the pages are plain HTML, written directly. They are *not* generated by
the jemdoc tool, so there are no `.jemdoc` source files to rebuild from — just
edit the HTML.

## Files

- `index.html` — About Us: intro
- `people.html` — Members: professor (name only, linked to `bio.html`),
  current members, alumni (names only, no photos by choice)
- `bio.html` — the professor's bio (career history, Google Scholar link);
  linked from `people.html`, not in the sidebar menu
- `research.html` — Research interests
- `publications.html` — Conference and journal papers
- `join.html` — Information for prospective students
- `contact.html` — Contact: email
- `jemdoc.css` — stock jemdoc stylesheet (do not edit unless you want to
  deviate from the template)

## How to edit

- **Add a paper**: in `publications.html`, copy an existing `<ul>...</ul>` block
  (each paper is its own list, as in the SDS site) and insert it at its
  chronological position: papers form one flat list, newest first, with
  conference ([C#]) and journal ([J#]) papers interleaved by actual
  publication date (no section or year headings). The format is: label, then the
  `<a href>`-wrapped `<font color=DarkBlue>` title (link to arXiv if available,
  otherwise the publisher DOI), then authors with lab members in `<b>`, then
  the venue on the last line as `Venue Full Name (ABBREV), YEAR (note)`.
  Authors are joined by commas with a final `, and` (no comma for two authors).
  Equal contribution / corresponding author are marked with `*` / `^` followed
  by an inline note, e.g. `(*: equal contribution)`. Papers also presented at a
  workshop get a `/W` label suffix and an extra venue line for the workshop.
- **Add a member**: in `people.html`, add an `<li>` to the appropriate list,
  formatted as `Name (M.S.-Ph.D. Integrated Student, Mon. YYYY -)` for current
  members or `Name (M.S. YYYY)` for alumni, with the name linked to their
  homepage if they have one. No photos.
- **Change the menu**: the `<td id="layout-menu">` block is repeated at the top
  of all six pages — edit each one if you add a page, and mark the current
  page's link with `class="current"`.

## How to publish

1. **GitHub Pages (free)**: create a repo, push these files, enable Pages in the
   repo settings. No build step is needed.
2. **University hosting**: upload the files as-is.
